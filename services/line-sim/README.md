# line-sim

C++20 edge producer. Reads a scenario stream (pre-generated by `qgate-gen` into newline-delimited JSON, or a scenario YAML it expands itself) and publishes to Redpanda **at takt**: one vehicle advances one station per takt, scaled by `REPLAY_SPEED`.

| File | Responsibility |
|---|---|
| `src/main.cpp` | CLI (`--scenario`, `--speed`, `--seed`, `--bootstrap`), wiring, signal handling |
| `src/scheduler.{hpp,cpp}` | Takt clock: maps sequence number → wall-clock emit time; monotonic, drift-corrected |
| `src/producer.{hpp,cpp}` | librdkafka wrapper: Avro (Confluent wire format) or JSON encoding, keyed by VIN/station, delivery callbacks, `/metrics` counters |
| `src/scenario_reader.{hpp,cpp}` | Parses `scenarios/*.yaml`, yields ordered events |
| `tests/` | Catch2: scheduler timing invariants, scenario parsing |

Build only inside Docker (`make unit` runs the test stage). The Python replay producer in `packages/qgate-generator` is the fallback (`--producer=python`).
