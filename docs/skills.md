# What a reviewer can open

Each row names the artefact and how it was exercised. A concern with no artefact is not claimed
here; one out-of-scope item is listed at the end so the boundary is explicit. Dates are the day
the evidence was produced on a laptop or a CI runner — none of it is a plant.

| Concern | Artefacts | Exercised how |
|---|---|---|
| Manufacturing / quality domain | [`scenarios/line.yaml`](../scenarios/line.yaml) (30 stations, 38 characteristics, shifts, benches), seven defect scenarios in [`scenarios/`](../scenarios), [`knowledge/fault_map.yaml`](../knowledge/fault_map.yaml), containment by window / lot / single, escape asymmetry in [`docs/eval.md`](eval.md) and [`docs/roi.md`](roi.md) | 50 golden cases authored from ground truth, frozen at `goldens-v1.1` |

| SPC / change-point (ML foundation) | Western Electric rules + EWMA in [`spc.py`](../services/detect/src/qgate_detect/spc.py); PELT + CUSUM onset with step-vs-drift by slope t-statistic in [`changepoint.py`](../services/detect/src/qgate_detect/changepoint.py) | 14 unit tests incl. plateau and lone-early-defect; onset within ±15 takts on every drift golden |
| Synthetic data & replay | Generator with ground truth in [`packages/qgate-generator`](../packages/qgate-generator); Avro contracts in [`schemas/`](../schemas); manifest export for the C++ replayer ([ADR-011](adr/0011-cpp-replays-exported-stream.md)) | Hypothesis-style determinism tests; 138 624 events replayed with Postgres counts equal to the manifest |

| Operator ↔ management | [`RUNBOOK.md`](../RUNBOOK.md) for the shift leader, [`docs/roi.md`](roi.md) for the plant manager, [`docs/adr`](adr) for the architect | three audiences, one repo |

**Out of scope, not claimed:** distributed batch processing (a Spark job over a few thousand
vehicles would be theatre); TLS, OIDC, network policies and audit-log immutability (listed as not
done in the README).
